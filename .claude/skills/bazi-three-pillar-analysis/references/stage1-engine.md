# Stage 1:三柱排盤引擎(命盤技術檔案產生規範)

任務:不寫文章,只產出結構化 JSON。這份 JSON 是後續四章的唯一事實來源。

與四柱版的根本差異:證據只有六個字(三天干+三地支含藏干)。引擎的職責不只是「用六個字推」,而是**明確記錄哪些判定因缺時柱而降級、降到什麼程度**——這些記錄(confidence、missing_hour_notes、hour_unlock)會直接餵給報告的開頭標註與收尾附註。

## 十步推導鏈(依序執行,不可跳步)

### Step 1:日主定性 + 意象化
- 確認日主天干與五行屬性(不受缺時柱影響,照四柱版原樣處理)
- 給出「具象、有溫度、有時間感」的比喻,必須同時暗示原始性格與當前處境
- 比喻公式:日主本體 + 月令環境修飾
- 範例:壬水生卯月=「凌晨一點的海面——天黑、風冷、水還在動,但方向感不穩」;丙火生子月=「寒冬正午的太陽——光是有的,但暖不到地面」;甲木生申月=「初秋的大樹——枝葉還茂,根已經感覺到風向變了」

### Step 2:身強弱判定(全文總開關)+ 翻盤測試
六字證據鏈:月令對日主的生剋 → 年支/日支通根 → 年干/月干幫扶 → 綜合定案。

**翻盤測試(三柱版核心工序,必跑):**
1. 假設缺失的時柱是「最幫身」的極端(通根+幫扶最大化)→ 判定會變成什麼?
2. 假設缺失的時柱是「最剋洩」的極端(剋洩耗最大化)→ 判定會變成什麼?
3. 對照結果定 confidence:
   - **高**:兩種極端下判定都不翻(例:月令+雙支通根的身強盤,再剋洩也強)→ 照判定寫,敘事同四柱版
   - **中**:極端情況會從「強/弱」滑到「中和偏強/偏弱」→ 判定保留,但 life_theme 用「偏」字措辭
   - **低**:極端情況會整個翻盤(弱變強或強變弱)→ 採保守的「中和偏X」判定,X 取六字證據指向的一側;處方章節降風險(見 Step 7)
- 判定值:身強 / 身弱 / 中和偏強 / 中和偏弱
- 產出 life_theme 一句話:
  - 身弱型:「對別人很有用,但對自己很耗損——輸出多、回收慢」
  - 身強型:「不怕扛,怕沒得扛——能量太滿,沒出口就內耗成脾氣」
  - 中和型:「能屈能伸,但也因此常常不知道自己真正要哪一邊」
- flip_risk 欄位記錄翻盤測試的兩個極端結果,寫給自己看,不進報告內文

### Step 3:五行分布盤點
- 木火土金水各自強度(三天干+三地支藏干都算),標 excess 與 deficient
- 分母是六字,不是八字:excess/deficient 的判定門檻相應收斂——某五行「完全不見於六字」仍標 deficient,但在 missing_hour_notes 記一筆「該五行可能藏於時柱」

### Step 4:十神定位 + 心理功能翻譯
每顆有力量的十神產出:十神名 / 落點(干支+宮位)/ 心理功能翻譯。

宮位意涵(三柱版):年柱=長輩/家世/早年,月柱=事業宮/社會我,日支=配偶宮/私我。
**時柱(子女/晚年/下屬/私領域深層)不在盤面上,相關主題不論。**

翻譯基準表(身弱盤方向;身強盤將「壓力源」翻為「可運用資源」;中和偏X盤依偏向側取用,措辭放軟):
| 十神 | 心理功能(身弱視角) | 心理功能(身強視角) |
|---|---|---|
| 比肩/劫財 | 自尊心、同輩緣、賭性;錢流向朋友的破口 | 兄弟撐腰、競爭力、敢分敢搶 |
| 食神 | 想法多、創造欲,但輸出耗身 | 才華變現的管道、生活情趣 |
| 傷官 | 不服管、心裡一堆OS、壓力下用說和想紓壓 | 敢挑戰權威、破格創新的武器 |
| 正財/偏財 | 金錢焦慮、現實壓力、「看到錢才安心」 | 掌控資源的能力、目標感 |
| 正官/七殺 | 被制度壓、喘不過氣的自我要求 | 地位、權柄、扛得起的責任 |
| 正印/偏印 | 想太多、自我審查;偏印過重=計畫一堆行動卡住 | 學習力、靠山、非常規解題腦 |

### Step 5:矛盾對提取(性格篇骨架,2~3 組)
格式:`[能量A] vs [能量B] → surface_behavior(外顯)/ inner_truth(內心真實)`
萃取原則:找命盤中「方向相反且都有力量」的組合,常見套路:
- 食傷旺 vs 身弱 → 想法多但不敢扛
- 傷官 vs 官殺 → 表面守規矩、心裡在造反
- 比劫旺 vs 財弱 → 自尊高但現實跟不上
- 印重 vs 食傷 → 想清楚了才動,結果都不動
- 財旺 vs 身弱 → 慾望大於體力,越追越累

三柱版注意:矛盾對的 A、B 都必須是六字裡實際存在的能量;不可用「時柱可能有X」當任何一邊。

### Step 6:神煞盤點(風味劑,不承擔核心邏輯)
華蓋、桃花(咸池)、紅艷、災煞、地煞、驛馬、魁罡等,各附一句生活化解讀。
三柱版規則:
- 查表基準(年支/日支/日干)都在,照查;**落點只認年支/月支/日支**——查表結果指向時支的,略過不列
- 桃花、驛馬等若不現於三柱,在 missing_hour_notes 記「可能落於時支」,供收尾附註使用,內文不寫
- 解讀原則:每個神煞給「走偏 vs 走正」兩面(例:華蓋走偏=自我封閉,走正=洞察型專業)

### Step 7:用神/忌神判定
- favorable / unfavorable 五行 + 理由
- 用忌神跟著身強弱連動,因此 **confidence 直接繼承 Step 2 的判定**:
  - confidence 高/中 → 照常給,處方照四柱版力度
  - confidence 低 → 用忌神照保守判定給,但在 JSON 標 `prescription_mode: "conservative"`:四章處方以「節奏、制度、邊界」類建議為主(不依賴五行方向也成立的),顏色/方位類斷語減量並收斂力度
- 翻成生活語言:
  - favorable_life:該靠近的環境、節奏、顏色、人的類型
  - unfavorable_life:會榨乾這個人的環境、節奏、關係型態

### Step 8:大運時間軸
- 大運排列由月柱+年干陰陽+性別推排,**不受缺時柱影響**,照四柱版處理
- 起運歲數需精確出生時刻計算節氣距離;不知時辰時誤差通常在數月內——標註為推算值,解讀時給 ±1 歲彈性,交界年份的敘事不寫死到「就是那一年」
- 每步大運:歲數區間 / 干支 / 十神屬性 / 一句話定調
- 定調詞庫:窒悶期、硬撐期、佈局防守期、耗損期、翻身期、收割期、稱王期、交棒期
- 定調邏輯:忌神運=壓力敘事,用神運=翻身敘事;當前大運要講最細

### Step 9:關鍵流年標記
範圍:當前年份起 15 年內。
只挑與原局三支/大運有明確互動的年份:沖(尤其沖日支/月支)、三合半合、財星透干、官殺透干、伏吟、用神到位。
三柱版限制:**互動機制只認年支/月支/日支與天干**;無法偵測沖時支/合時支,不硬補、不臆測。
每個流年:年份(歲數)/ 干支 / 互動機制 / 事件傾向(財/感情/變動/風險)/ 吉凶方向。
**嚴禁**:沒有機制依據的年份硬塞進表;干支紀年不確定時先驗算(公元年-3)除以60的餘數對照六十甲子。

### Step 10:配偶宮 + 感情素材
- 配偶宮=日支,**完整保留,照四柱版處理**:日支藏干 → 配偶性格氣質種子
- 財星(男命)/官星(女命)落點 → 相遇場域(掛事業宮=職場半徑;掛年柱=舊識/家族圈半徑)
- 財(官)星不現於三柱時:合法推論是「明面上緣分不顯山露水——來得低調、來得慢熱」,並在 missing_hour_notes 記「財(官)星可能藏於時柱,若然則偏晚遇/私領域」;**內文只寫前者,不寫後者的臆測**
- 桃花神煞落點:只認三柱落點(如桃花在日支=緣分近身、日常半徑內);不現則從日支藏干+日主氣質推「連結如何發生」

## Step 11(收尾):時辰解鎖清單產出
從本次推導的 missing_hour_notes 挑 2~3 條,轉譯成 hour_unlock 陣列——「找回出生時間後可以解鎖什麼」,語氣是加開檔案,不是道歉:
1. 固定一條:身強弱與用忌神定案 → 顏色/方位/環境處方精度升級
2. 固定一條:子女宮/晚年運檔案解鎖
3. 機動一條:依 missing_hour_notes 取最有感的(例:桃花可能藏於時支 → 相遇情境還原;流年沖合時支 → 年份劇本精細化)

## 品質檢核
- 身強弱判定的 reasoning 必須列出月令、通根(年支/日支)、幫扶(年干/月干)三項證據,且 flip_risk 必須記錄翻盤測試兩個極端的結果
- 每組矛盾對的 A、B 都必須是 ten_gods 裡實際存在的能量
- key_years 每筆的 ganzhi 必須與 year 對得上(用六十甲子驗算),機制欄不得出現時支
- 大運排列若為推算值,在輸出時明確標註;起運歲數一律標 ±1 歲彈性
- **JSON 任何欄位不得出現時柱干支或對時柱內容的推測**(missing_hour_notes 只記「什麼查不到」,不記「時柱可能是什麼干支」)
