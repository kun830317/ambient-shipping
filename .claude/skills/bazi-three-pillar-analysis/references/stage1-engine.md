# Stage 1:三柱排盤引擎(命盤技術檔案產生規範)

任務:不寫文章,只產出結構化 JSON。這份 JSON 是後續八章的唯一事實來源。

與四柱版(v6)的根本差異:證據只有六個字(三天干+三地支含藏干)。引擎的職責不只是「用六個字推」,而是**明確記錄哪些判定因缺時柱而降級、降到什麼程度**,並**補回三組不需要時辰的結構論點**,讓報告的資訊密度與 v6 相當。

## 論點總量守恆(三柱版設計原則)

缺時柱會拿掉一批論點(時柱十神、時支藏干、時柱神煞、子女宮、私領域深層宮)。補回三組:

| 補償論點 | 為什麼三柱一定看得到 | 餵給哪些章節 |
|---|---|---|
| 三柱關係軸(Step 5) | 沖合刑害只需要有支就能查,三支之間的關係完全成立 | 1-1第二幕、1-2、4-1、6-1、7-1 |
| 旬空(Step 9) | 由日柱/年柱所在旬推,與時辰無關 | 2-3、2-4、3-4、7-2 |
| 宮位遞進敘事軸(Step 11) | 年→月→日 本身就是「出身→社會→自我」的完整時間軸 | 1-1、6-1、7-1 |

**這三組不是補丁,是三柱版的招牌菜。**v6 把注意力分散在四宮,三柱版把同樣的力氣集中在三宮的關係上。

## 十六步推導鏈(依序執行,不可跳步)

### Step 1:基礎資料與干支驗算
- 三柱干支;**一律程式驗算**(六十甲子序位),不心算
- 節氣定月柱;生日落在節氣交界兩日內須先驗節氣
- 生肖、月令旺衰、日主陰陽
- **不做真太陽時校正**——該校正只影響時柱,無時辰時不適用,命盤頁該欄位直接不列(不可留空格或寫「未知」佔位)
- 起運歲數:由月柱+年干陰陽+性別推排;無時辰時無法精算節氣距離,一律標推算值並給 ±1 歲彈性

### Step 2:十神力量值量化(v6 核心,務必產出數值)
產出五股能量的力量值:比劫 / 食傷 / 財 / 官殺 / 印。
- 計分基礎:天干本氣、地支本氣、地支中氣/餘氣藏干,依月令旺衰與位置加權
- **分母是六字不是八字**:力量值必須標註 `base: "six_char"`,並在命盤頁註明「六字盤點」。三柱盤的絕對值天生低於四柱盤,**嚴禁把數值拿去跟四柱盤比大小**,只看盤內五股的相對比例
- 產出 five_powers:各股數值 + 排序 + 標記 excess / 掛零(掛零本身是重量級論點,如「比劫 0=沒有隊友欄」)
- 同時產出 five_elements(木火土金水含藏干的份數)與 excess / deficient

### Step 3:通根與蓋頭截腳
- 每柱:通根強度(虛浮 0.00 / 根重 x.xx 之類的數值化描述)、蓋頭 / 截腳 / 得生
- 日主通根是身強弱的第一證據,務必逐柱列出

### Step 4:身強弱判定(全文總開關)+ 翻盤測試(數值化)
六字證據鏈:月令對日主的生剋 → 年支/日支通根 → 年干/月干幫扶 → 綜合定案。

**翻盤測試(三柱版核心工序,必跑,且要用數值表達):**
1. 假設缺失的時柱為「最幫身」極端(印比同透且帶根)→ 五股力量值各自最多加多少?判定變成什麼?
2. 假設為「最剋洩」極端(財官食傷透干帶根)→ 同上
3. 定 confidence:
   - **高**:兩極端下判定都不翻 → 照判定寫,力度等同 v6
   - **中**:極端下會從「強/弱」滑到「中和偏強/偏弱」→ 判定保留,life_theme 用「偏」字措辭
   - **低**:極端下整個翻盤 → 採保守的「中和偏X」判定,X 取六字證據指向側;`prescription_mode: conservative`
- flip_risk 記錄兩極端的數值區間與結論,寫給引擎自己看,不進報告內文
- 產出 life_theme 一句話(身弱型「對別人很有用,但對自己很耗損」/身強型「不怕扛,怕沒得扛」/中和型「能屈能伸,卻常不知道自己要哪一邊」)

### Step 5:三柱關係軸(補償論點一,必跑)
**地支關係(年↔月、月↔日、年↔日 三組全查):**
- 六合、三合(足三支才算成局)、半合(須含中神)、三會方局、相沖、相刑(含自刑)、相害
- **成局判定要嚴**:三合只到兩支且缺中神 → 記「有合意、不成局」,不可當成局論;缺的那一支若可能落在時支,記入 missing_hour_notes 並成為 hour_unlock 的最強素材
- **合化須回頭校正**:查出合化(如辰酉合化金)會加重某五行時,回 Step 2/4 校正力量值與強弱,不可各說各話

**天干關係:** 五合(甲己/乙庚/丙辛/丁壬/戊癸)、生剋連氣。產出 gan_chain 一句話——三個天干是「一路生身」「一路剋洩」還是「有生有剋」,直接對應「有沒有人管得動你」。

每組產出:pair / type / element_effect / life_interpretation。

**宮位翻譯對照:**
| 配對 | 宮位含義 | 論點方向 |
|---|---|---|
| 年↔月 | 家世 ↔ 事業 | 出身對職涯是推力還是阻力 |
| 月↔日 | 事業 ↔ 自我/親密 | 工作與生活是同一股氣還是兩個世界 |
| 年↔日 | 長輩/家族 ↔ 配偶/自我 | 家族圈與親密關係的連動(相合=緣分從舊識/家族半徑來;相沖=兩邊拉扯) |

**三柱全無沖刑**時,本身是重量級論點:結構沒有內建斷裂點 → 對應「長期被壓型」而非「出大事型」的厄運型態(餵 7-1)。

### Step 6:格局命名
依身強弱+五股比例,給格局正式名稱與古典比喻(如財多身弱=富屋貧人、殺印相生、身輕擔重、食傷洩身、金白水清)。
- 產出 pattern.name / pattern.classical / pattern.one_liner
- **one_liner 是封面那一行定調**(v6 封面:「財殺旺而身弱・殺印相生・用神印」),格式:格局 + 機制 + 用神,以「・」分隔

### Step 7:大自然地形圖(三柱版:三塊地形)
v6 用四塊地形(日=本位、月=近景、年=遠景、時=深淵)。三柱版只有三塊,**依「由自己往外看」的順序**:
| 地形 | 對應柱 | 定位 |
|---|---|---|
| 本位 | 日柱 | 你自己站的那塊地 |
| 近景 | 月柱 | 當令環境、最貼身的世界 |
| 遠景 | 年柱 | 根源、祖上、目光最遠處 |

每塊產出:element(五行圖示)/ pillar_label / imagery_headline(一句有畫面的意象標題)/ body(意象展開+藏干拆解+引擎數據)。
**「深淵」那塊地不存在於三柱盤——不畫、不虛構、不用文字解釋為什麼少一塊。**第一幕就是三張卡,讀起來自然完整。
補償:第二幕的機制條目從 v6 的 5 條增為 6~7 條(把 Step 5 關係軸的發現補進去),讓 1-1 的總資訊量不低於 v6。

### Step 8:十神定位 + 心理功能翻譯
每顆有力量的十神:十神名 / 落點(干支+宮位)/ 心理功能翻譯。
宮位意涵:年柱=長輩/家世/早年,月柱=事業宮/社會我,日支=配偶宮/私我。**時柱的子女/晚年/私領域深層不在盤面上,相關主題不論。**

翻譯基準表(身弱盤方向;身強盤將「壓力源」翻為「可運用資源」;中和偏X依偏向側取用、措辭放軟):
| 十神 | 心理功能(身弱視角) | 心理功能(身強視角) |
|---|---|---|
| 比肩/劫財 | 自尊心、同輩緣、賭性;錢流向朋友的破口 | 兄弟撐腰、競爭力、敢分敢搶 |
| 食神 | 想法多、創造欲,但輸出耗身 | 才華變現的管道、生活情趣 |
| 傷官 | 不服管、心裡一堆OS、壓力下用說和想紓壓 | 敢挑戰權威、破格創新的武器 |
| 正財/偏財 | 金錢焦慮、現實壓力、「看到錢才安心」 | 掌控資源的能力、目標感 |
| 正官/七殺 | 被制度壓、喘不過氣的自我要求 | 地位、權柄、扛得起的責任 |
| 正印/偏印 | 想太多、自我審查;偏印過重=計畫一堆行動卡住 | 學習力、靠山、非常規解題腦 |

**某十神完全不現於六字時**:這是論點不是空白。合法寫法是「該功能在明面上不運作」(例:官殺不現=沒有外部的尺,標準全部自己訂);臆測「可能藏在時柱」只進 missing_hour_notes。

### Step 9:旬空(補償論點二,必跑)
- 以**日柱**旬推主空亡,**年柱**旬推次空亡;算法:定序位 → 旬首 = 序位//10*10 → 空亡二支 = 旬首地支往後推 10、11 位。**須程式驗算**
- in_chart:三柱地支是否有落空者
  - 有落空 → 該宮位翻成「感覺不太實在」(年支落空=與家族連結感淡;月支落空=事業有種做了抓不到的虛感)
  - 無落空 → 好論點:三塊宮位都「實」,沒有天生虛耗的區塊
- **與流年/大運交叉**:空亡支對應的年份是「氣勢到了但落地打折」。若空亡支剛好是命局三合缺的中神,這是全報告最有張力的論點之一:**你最需要的那個出口,天生帶著抓不太到的性質**,必附條件式出口
- 筆法紅線:空亡是「打折」不是「凶」

### Step 10:神煞盤點(逐柱,吉/凶/中性分類)
華蓋、桃花(咸池)、紅艷、紅鸞、將星、國印貴人、天醫、德秀貴人、太極貴人、驛馬、飛刃、流霞、勾絞煞、魁罡等。
- 查表基準(年支/日支/日干)都在,照查;**落點只認年支/月支/日支**,指向時支者略過不列
- 每顆標 kind: 吉神 / 凶煞 / 中性(命盤頁據此上色)
- 每顆附一句生活化解讀,並給「走偏 vs 走正」兩面
- 不現於三柱的桃花、驛馬等,記入 missing_hour_notes,內文不寫

### Step 11:宮位遞進敘事軸(補償論點三,必跑)
- year_palace:出身給了什麼、欠了什麼
- month_palace:社會場上你被放在什麼位置
- day_palace:回到自己與親密關係時你是什麼樣子
- **arc_sentence**:一句話串起三段的遞進或斷裂,必須有「因為前一段,所以下一段」的因果

### Step 12:用神/忌神 + 生存處方素材
- favorable / unfavorable 五行 + 理由;用神 / 喜神分開標
- confidence 繼承 Step 4:低 → `prescription_mode: conservative`(處方主力改押節奏、制度、邊界類,顏色方位類收斂)
- 產出 prescription 五列素材:方向 / 顏色 / 環境 / 物品 / 應避免的情況(各給用神側與忌神側)

### Step 13:大運時間軸 + 走勢評分
- 大運排列由月柱+年干陰陽+性別推排,不受缺時柱影響
- 每步:歲數區間 / 干支 / 十神 / 一句話定調 / **score(-2~+2,用於走勢圖)**
- 定調詞庫:窒悶期、硬撐期、佈局防守期、耗損期、翻身期、收割期、稱王期、交棒期
- 標記 current(當前大運),當前大運要講最細
- 起運為推算值 → 走勢圖 x 軸標註「起運為推算值 ±1 歲」

### Step 14:關鍵流年 + 窗口
範圍:當前年份起 15 年內。只挑與原局三支/大運有明確互動的:沖(尤其沖日支/月支)、三合半合、三會、財星透干、官殺透干、伏吟、用神到位、**補齊原局缺中神而成局**、**落於旬空**。
- 每筆:年份(歲數)/ 干支 / 機制 / 事件傾向 / 吉凶方向 / void 標記 / score(走勢圖圓點)
- **限制**:機制只認年支/月支/日支與天干;無法偵測沖時支/合時支,不硬補
- **連續成局優先**:連續 2~3 年構成三會或三合 → 併入 key_windows,寫成「窗口」而非獨立年份
- 干支驗算:(公元年-4) mod 60 對照六十甲子

### Step 15:六親與人際素材
- 配偶宮=日支(完整保留):藏干 → 配偶氣質種子;財星(男命)/官星(女命)落點 → 相遇場域;**與 Step 5 關係軸交叉**(年支合日支→家族/舊識半徑;月支連日支→職場半徑)
- 父母:父星(男命偏財/女命亦取財星)、母星(印星)落點與力量
- **手足與同輩:比劫力量值 + 落點**——這是三柱版 6-3 的主素材(取代 v6 的子女宮)
- 貴人:Step 10 的吉神依「名分型 / 蔭庇療癒型 / 人氣型」分三類

### Step 16:時辰解鎖清單
從 missing_hour_notes 挑 3 條轉成 hour_unlock,語氣是加開檔案不是道歉:
1. 固定:身強弱與用忌神定案 → 力量值與處方精度升級
2. 固定:子女宮與晚年運檔案解鎖(這是三柱版唯一整節缺席的主題)
3. 機動,**優先取 Step 5 的「缺中神不成局」**——最有畫面、最讓人想去查戶政的一條

## 品質檢核
- 干支、旬空、流年、六十甲子序位一律程式驗算,不心算
- five_powers 必須標 base 與 note;三柱盤的數值不得與四柱盤比大小
- 身強弱 reasoning 須列月令、通根(年支/日支)、幫扶(年干/月干)三項;flip_risk 須含兩極端的數值區間
- pillar_relations 必須把年↔月、月↔日、年↔日 三組都查過(無關係也記「無」);查出合化須已回頭校正 Step 2/4
- 三合/三會只到兩支且缺中神者,type 必須寫「不成局」,缺支已進 missing_hour_notes
- terrain 必須恰好三塊,**不得出現第四塊或任何時柱地形**
- xunkong 旬首與空亡二支須驗算
- palace_arc.arc_sentence 須看得出因果,不可三句並列
- key_years 的 ganzhi 與 year 必須對得上;機制欄不得出現時支;連續成局須併入 key_windows
- 命盤頁不列真太陽時校正欄(無時辰時該欄不適用)
- **JSON 任何欄位不得出現時柱干支或對時柱內容的推測**(missing_hour_notes 只記「什麼查不到」與「缺哪一支會成什麼局」)
