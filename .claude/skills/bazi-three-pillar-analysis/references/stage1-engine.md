# Stage 1:三柱排盤引擎(命盤技術檔案產生規範)

任務:不寫文章,只產出結構化 JSON。這份 JSON 是後續四章的唯一事實來源。

與四柱版的根本差異:證據只有六個字(三天干+三地支含藏干)。引擎的職責不只是「用六個字推」,而是**明確記錄哪些判定因缺時柱而降級、降到什麼程度**——這些記錄(confidence、missing_hour_notes、hour_unlock)會直接餵給報告的開頭標註與收尾附註。

## 論點總量守恆(三柱版設計原則)

缺時柱會拿掉一批論點(時柱十神、時支藏干、時柱神煞、子女宮、晚年宮)。為了讓報告的資訊密度與四柱版一致,本引擎**補回三組不需要時辰、且四柱版常常帶過的結構論點**:

| 補償論點 | 為什麼三柱一定看得到 | 餵給哪些章節 |
|---|---|---|
| 三柱關係軸(Step 4) | 沖合刑害只需要有支就能查,三支之間的關係完全成立 | 1-2、1-4、3-1、4-1 |
| 旬空/空亡(Step 8) | 由日柱(或年柱)所在旬推,與時辰無關 | 2-3、2-4、4-2 |
| 宮位遞進敘事軸(Step 10) | 年→月→日 本身就是「出身→社會→自我」的完整時間軸 | 1-1、4-1 |

**這三組不是補丁,是三柱版的招牌菜。**四柱版把注意力分散在四個宮位,三柱版把同樣的力氣集中在三個宮位的關係上,深度反而更容易做出來。

## 十四步推導鏈(依序執行,不可跳步)

### Step 1:日主定性 + 意象化
- 確認日主天干與五行屬性(不受缺時柱影響,照四柱版原樣處理)
- 給出「具象、有溫度、有時間感」的比喻,必須同時暗示原始性格與當前處境
- 比喻公式:日主本體 + 月令環境修飾
- 範例:壬水生卯月=「凌晨一點的海面——天黑、風冷、水還在動,但方向感不穩」;丙火生子月=「寒冬正午的太陽——光是有的,但暖不到地面」;甲木生申月=「初秋的大樹——枝葉還茂,根已經感覺到風向變了」

### Step 2:身強弱判定(全文總開關)+ 翻盤測試
六字證據鏈:月令對日主的生剋 → 年支/日支通根 → 年干/月干幫扶 → 綜合定案。

**翻盤測試(三柱版核心工序,必跑):**
1. 假設缺失的時柱是「最幫身」的極端(通根+幫扶最大化)→ 判定會變成什麼?
2. 假設缺失的時柱是「最剋洩」的極端(剋洩耗最大化)→ 判定會變成什麼?
3. 對照結果定 confidence:
   - **高**:兩種極端下判定都不翻(例:月令+雙支通根的身強盤,再剋洩也強)→ 照判定寫,敘事同四柱版
   - **中**:極端情況會從「強/弱」滑到「中和偏強/偏弱」→ 判定保留,但 life_theme 用「偏」字措辭
   - **低**:極端情況會整個翻盤(弱變強或強變弱)→ 採保守的「中和偏X」判定,X 取六字證據指向的一側;處方章節降風險(見 Step 9)
- 判定值:身強 / 身弱 / 中和偏強 / 中和偏弱
- 產出 life_theme 一句話:
  - 身弱型:「對別人很有用,但對自己很耗損——輸出多、回收慢」
  - 身強型:「不怕扛,怕沒得扛——能量太滿,沒出口就內耗成脾氣」
  - 中和型:「能屈能伸,但也因此常常不知道自己真正要哪一邊」
- flip_risk 欄位記錄翻盤測試的兩個極端結果,寫給自己看,不進報告內文

### Step 3:五行分布盤點
- 木火土金水各自強度(三天干+三地支藏干都算),標 excess 與 deficient
- 分母是六字,不是八字:excess/deficient 的判定門檻相應收斂——某五行「完全不見於六字」仍標 deficient,但在 missing_hour_notes 記一筆「該五行可能藏於時柱」

### Step 4:三柱關係軸(補償論點一,必跑)
查完三組配對關係,這是三柱版最肥的結構材料:

**地支關係(年↔月、月↔日、年↔日 三組全查):**
- 六合、三合(足三支才算成局)、半合(須含中神)、三會方局
- 相沖、相刑(含自刑)、相害
- **成局判定要嚴**:三合只到兩支且缺中神 → 記為「有合意、不成局」,不可當成局論;缺的那一支若可能落在時支,記入 missing_hour_notes 並成為 hour_unlock 的最強素材

**天干關係:** 五合(甲己/乙庚/丙辛/丁壬/戊癸)、生剋連氣。產出 gan_chain 一句話——三個天干是「一路生身」「一路剋洩」還是「有生有剋」,這句直接對應「有沒有人管得動你」的心理論點。

**回頭校驗**:若查出合化(如辰酉合化金)會加重某五行,回 Step 2/3 校正強弱與五行分布,不可各說各話。

每組關係產出:pair(哪兩柱)/ type(合/沖/刑/害/連氣)/ element_effect(對五行的實際影響)/ life_interpretation(宮位翻譯)。

**宮位翻譯對照:**
| 配對 | 宮位含義 | 論點方向 |
|---|---|---|
| 年↔月 | 家世 ↔ 事業 | 出身對職涯是推力還是阻力 |
| 月↔日 | 事業 ↔ 自我/親密 | 工作與生活是同一股氣還是兩個世界 |
| 年↔日 | 長輩/家族 ↔ 配偶/自我 | 家族圈與親密關係的連動(相合=緣分從舊識/家族半徑來;相沖=兩邊拉扯) |

**三柱全無沖刑**時,這本身是重量級論點:結構沒有內建斷裂點 → 對應「長期被壓型」而非「出大事型」的厄運型態(餵 4-1)。

### Step 5:十神定位 + 心理功能翻譯
每顆有力量的十神產出:十神名 / 落點(干支+宮位)/ 心理功能翻譯。

宮位意涵(三柱版):年柱=長輩/家世/早年,月柱=事業宮/社會我,日支=配偶宮/私我。
**時柱(子女/晚年/下屬/私領域深層)不在盤面上,相關主題不論。**

翻譯基準表(身弱盤方向;身強盤將「壓力源」翻為「可運用資源」;中和偏X盤依偏向側取用,措辭放軟):
| 十神 | 心理功能(身弱視角) | 心理功能(身強視角) |
|---|---|---|
| 比肩/劫財 | 自尊心、同輩緣、賭性;錢流向朋友的破口 | 兄弟撐腰、競爭力、敢分敢搶 |
| 食神 | 想法多、創造欲,但輸出耗身 | 才華變現的管道、生活情趣 |
| 傷官 | 不服管、心裡一堆OS、壓力下用說和想紓壓 | 敢挑戰權威、破格創新的武器 |
| 正財/偏財 | 金錢焦慮、現實壓力、「看到錢才安心」 | 掌控資源的能力、目標感 |
| 正官/七殺 | 被制度壓、喘不過氣的自我要求 | 地位、權柄、扛得起的責任 |
| 正印/偏印 | 想太多、自我審查;偏印過重=計畫一堆行動卡住 | 學習力、靠山、非常規解題腦 |

**某十神完全不現於六字時**:這是論點不是空白。合法寫法是「該功能在明面上不運作」(例:官殺不現=沒有外部的尺,標準全部自己訂);臆測「可能藏在時柱」只進 missing_hour_notes,不進內文。

### Step 6:矛盾對提取(性格篇骨架,2~3 組)
格式:`[能量A] vs [能量B] → surface_behavior(外顯)/ inner_truth(內心真實)`
萃取原則:找命盤中「方向相反且都有力量」的組合,常見套路:
- 食傷旺 vs 身弱 → 想法多但不敢扛
- 傷官 vs 官殺 → 表面守規矩、心裡在造反
- 比劫旺 vs 財弱 → 自尊高但現實跟不上
- 印重 vs 食傷 → 想清楚了才動,結果都不動
- 財旺 vs 身弱 → 慾望大於體力,越追越累
- 身強 vs 官殺不現 → 配合度看起來高,其實誰都管不動(三柱版高頻出現,因為六字更容易整組缺席)

三柱版注意:矛盾對的 A、B 都必須是六字裡實際存在的能量,或「整組缺席」這個事實本身;不可用「時柱可能有X」當任何一邊。

### Step 7:神煞盤點(風味劑,不承擔核心邏輯)
華蓋、桃花(咸池)、紅艷、災煞、地煞、驛馬、魁罡、將星等,各附一句生活化解讀。
三柱版規則:
- 查表基準(年支/日支/日干)都在,照查;**落點只認年支/月支/日支**——查表結果指向時支的,略過不列
- 桃花、驛馬等若不現於三柱,在 missing_hour_notes 記「可能落於時支」,供收尾附註使用,內文不寫
- 解讀原則:每個神煞給「走偏 vs 走正」兩面(例:華蓋走偏=自我封閉,走正=洞察型專業)

### Step 8:旬空/空亡(補償論點二,必跑)
- 以**日柱**所在旬推主空亡(primary_void),以**年柱**所在旬推次空亡(secondary_void)
- 算法:定日柱在六十甲子的序位 → 旬首 = 序位整除10後乘10 → 空亡兩支 = 旬首地支往後推 10、11 位
- 記錄 in_chart:三柱地支中是否有落空者
  - **有落空**:該宮位翻成「感覺不太實在」的論點(空亡在年支=與家族的連結感淡、早年缺乏可靠依附;在月支=事業有種「做了但抓不到」的虛感;日支落空極少見,須複查)
  - **無落空**:這是好論點不是沒論點——三塊宮位都「實」,人生沒有天生虛耗的區塊
- **空亡與流年/大運交叉**:空亡兩支對應的流年、大運,是「氣勢到了但落地打折」的年份。若空亡支剛好是命局三合局的中神(常見於三柱盤),這是全報告最有張力的論點之一:**你最需要的那個出口,天生帶著抓不太到的性質**——必附條件式出口(把成果具體化成作品、合約、可交付物,空亡就吃不到你)
- 筆法紅線:空亡是「打折」不是「凶」,嚴禁寫成災厄

### Step 9:用神/忌神判定
- favorable / unfavorable 五行 + 理由
- 用忌神跟著身強弱連動,因此 **confidence 直接繼承 Step 2 的判定**:
  - confidence 高/中 → 照常給,處方照四柱版力度
  - confidence 低 → 用忌神照保守判定給,但在 JSON 標 `prescription_mode: "conservative"`:四章處方以「節奏、制度、邊界」類建議為主(不依賴五行方向也成立的),顏色/方位類斷語減量並收斂力度
- 翻成生活語言:
  - favorable_life:該靠近的環境、節奏、顏色、人的類型
  - unfavorable_life:會榨乾這個人的環境、節奏、關係型態

### Step 10:宮位遞進敘事軸(補償論點三,必跑)
把年→月→日 讀成一條完整的人生時間軸,產出 palace_arc:
- year_palace:出身給了什麼、欠了什麼(看年柱十神+關係軸)
- month_palace:社會場上你被放在什麼位置(看月柱十神,這是成年後主戰場)
- day_palace:回到自己與親密關係時,你是什麼樣子(看日支藏干)
- **arc_sentence**:一句話串起三段的遞進或斷裂(例:「被保護的出身 → 被並排競爭的職場 → 自己一個人也站得住的核心」)

這句 arc_sentence 是性格篇 1-1 的骨架備料,也是大運篇 4-1 講童年到現在的敘事主線。四柱版的敘事重心在四宮並列,三柱版改走「三段遞進」——這是三柱報告讀起來反而更有故事感的原因。

### Step 11:大運時間軸
- 大運排列由月柱+年干陰陽+性別推排,**不受缺時柱影響**,照四柱版處理
- 起運歲數需精確出生時刻計算節氣距離;不知時辰時誤差通常在數月內——標註為推算值,解讀時給 ±1 歲彈性,交界年份的敘事不寫死到「就是那一年」
- 每步大運:歲數區間 / 干支 / 十神屬性 / 一句話定調
- 定調詞庫:窒悶期、硬撐期、佈局防守期、耗損期、翻身期、收割期、稱王期、交棒期
- 定調邏輯:忌神運=壓力敘事,用神運=翻身敘事;當前大運要講最細

### Step 12:關鍵流年標記
範圍:當前年份起 15 年內。
只挑與原局三支/大運有明確互動的年份:沖(尤其沖日支/月支)、三合半合、三會方局、財星透干、官殺透干、伏吟、用神到位、**補齊原局缺中神而成局**、**落於旬空**。
三柱版限制:**互動機制只認年支/月支/日支與天干**;無法偵測沖時支/合時支,不硬補、不臆測。
每個流年:年份(歲數)/ 干支 / 互動機制 / 事件傾向(財/感情/變動/風險)/ 吉凶方向 / void 標記(是否落空亡)。
**連續成局優先**:若連續 2~3 個流年構成三會或三合(如亥子丑三會北方),必須合併標記為「窗口」而非各自獨立的年份——這是逆轉之年(4-3)最有力的素材。
**嚴禁**:沒有機制依據的年份硬塞進表;干支紀年不確定時先驗算(公元年-4)除以60的餘數對照六十甲子。

### Step 13:配偶宮 + 感情素材
- 配偶宮=日支,**完整保留,照四柱版處理**:日支藏干 → 配偶性格氣質種子
- 財星(男命)/官星(女命)落點 → 相遇場域(掛事業宮=職場半徑;掛年柱=舊識/家族圈半徑)
- **關係軸交叉(三柱版強化)**:年支與日支相合 → 相遇半徑明確指向家族圈/舊識/長輩牽線;月支與日支連氣 → 職場與私領域高度重疊,緣分幾乎必然來自工作半徑。這條比單看財官星落點精準得多,務必交叉後再定 meeting_context
- 財(官)星不現於三柱時:合法推論是「明面上緣分不顯山露水——來得低調、來得慢熱」,並在 missing_hour_notes 記「財(官)星可能藏於時柱」;**內文只寫前者,不寫後者的臆測**
- 桃花神煞落點:只認三柱落點(如桃花在日支=緣分近身、日常半徑內);不現則從日支藏干+日主氣質推「連結如何發生」

### Step 14:時辰解鎖清單
從本次推導的 missing_hour_notes 挑 2~3 條,轉譯成 hour_unlock 陣列——「找回出生時間後可以解鎖什麼」,語氣是加開檔案,不是道歉:
1. 固定一條:身強弱與用忌神定案 → 顏色/方位/環境處方精度升級
2. 固定一條:子女宮/晚年運檔案解鎖
3. 機動一條,**優先取 Step 4 查出的「缺中神不成局」**——這是最具體、最有說服力的解鎖點(例:「若時支見子,申子辰三合水局成立,你的輸出通道會從細縫變成閘門」)

## 品質檢核
- 身強弱判定的 reasoning 必須列出月令、通根(年支/日支)、幫扶(年干/月干)三項證據,且 flip_risk 必須記錄翻盤測試兩個極端的結果
- **pillar_relations 必須把年↔月、月↔日、年↔日 三組都查過**(無關係也要明確記「無」);查出合化時,Step 2/3 必須已回頭校正
- 三合/三會只到兩支且缺中神者,type 必須寫「不成局」,且缺支已進 missing_hour_notes
- xunkong 的旬首與空亡兩支必須用六十甲子序位驗算,不可憑印象
- palace_arc.arc_sentence 必須看得出三段遞進或斷裂,不可是三句並列的形容詞
- 每組矛盾對的 A、B 都必須是 ten_gods 裡實際存在的能量,或「整組缺席」的事實
