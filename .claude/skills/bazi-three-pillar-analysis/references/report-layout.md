# 交付版面規範(命格書 · 三柱版)

版面與 v6 四柱版**共用同一套設計語言與同一支渲染器**。差異只有三處:封面命柱卡三張、命盤頁三欄且不列真太陽時校正、多一頁附錄(時辰解鎖清單)。除此之外不得有任何版面差異——版面是產品識別,不是每次重新設計的東西。

## 交付雙檔

| 檔案 | 命名 |
|---|---|
| `.md`(內容本體,可再編輯) | `{稱呼}_命格書_三柱_{日期}.md` |
| `.pdf`(交付版) | `{稱呼}_命格書_三柱_{日期}.pdf` |

markdown 是唯一內容來源。**嚴禁為了排版好看而在 PDF 階段改內容**,要改就改 markdown 再重跑。

## 頁面構成(順序固定)

1. **封面**:雙線外框 + 點陣底紋;「八字命盤深度解析」小字 → 「命格書」大標 → 「{日主}日主・{稱呼}」→ 三張命柱卡(五行上色,干上支下)→ 短紅線 → 格局定調一行 → 右側直排「依你的盤・如實寫下」→ 左下五行圓環標誌 → 右下坤/乾紅印
2. **本書總覽**:◈ 標題;各章藏藍粗體 + 灰色副標 + 節次清單
3. **三柱命盤**:四角直角標記;◈ 標題;三欄 meta grid;主表(日柱表頭用紅色,其餘藏藍);天干地支大字上色;神煞依吉凶上色 + 圖例;天干互動/地支互動/五行分布;大運流轉條(當前一格highlight);底部一行標註「時辰未知,以年月日三柱(六字)論命」
4. **八章**:每章起新頁,章首=紅印章號(壹貳參…)+ 章名 + 灰副標 + 右側直排章籤 + 藏藍橫線
5. **附錄・時辰解鎖清單**:獨立一頁
6. **寫給日主的一封信**:居中寬字距標題,信體,右下落款 + 坤印

頁尾統一:`◍ 命 格 書 ・ 如 實`(小字灰)。

## 版面規格

- A4,邊界 `18mm 16mm 20mm`
- 內文 Noto Serif TC 10.5pt / 行高 1.95 / 左右對齊;`**粗體**`一律藏藍
- 標題與表格 Noto Sans TC
- 節標題 `◆ 1-1 xxx`:藏藍粗體 12pt,◆ 為紅色
- 幕標題:紅色、字距 .3em、10.5pt(如「第一幕 全景佈置:這片地長什麼樣」)
- 地形卡:卡片底 + 細框 + 圓角;左上五行圓形徽章(五行色底白字);柱位小灰字;意象標題藏藍粗體;內文 10pt
- OS 引文框:左側 3px 灰線,內文灰、稍小
- 章末 callout:區塊底 + 左側 4px 紅線,內文藏藍粗體
- 表格:藏藍表頭白字、偶列斑馬、`page-break-inside: avoid`
- 能量條圖:水平條,五行色,灰底軌,值標在條末,用神標註
- 大運走勢圖:階梯面積圖,順=綠、逆=紅;虛線標「現在」;關鍵流年畫圓點;x 軸干支+起歲

## 字型取得

環境常只有點陣中文字型,直接輸出會很醜。首選思源字型:

```bash
python3 - <<'PY'
import re, urllib.request, os
base = os.path.expanduser("~/fonts-web"); os.makedirs(base, exist_ok=True)
UA = {"User-Agent": "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 Chrome/120.0 Safari/537.36"}
css = ""
for fam, wts in [("Noto+Serif+TC", "400;700"), ("Noto+Sans+TC", "500;700")]:
    u = f"https://fonts.googleapis.com/css2?family={fam}:wght@{wts}&display=swap"
    css += urllib.request.urlopen(urllib.request.Request(u, headers=UA), timeout=60).read().decode() + "\n"
for i, u in enumerate(sorted(set(re.findall(r"url\((https://fonts\.gstatic\.com/[^)]+)\)", css)))):
    fn = f"f{i:03d}.woff2"
    open(os.path.join(base, fn), "wb").write(urllib.request.urlopen(urllib.request.Request(u, headers=UA), timeout=60).read())
    css = css.replace(u, fn)
open(os.path.join(base, "fonts.css"), "w").write(css)
PY
```

GitHub 的 noto-cjk 走 Git LFS,直接 curl 只會拿到 378 bytes 指標檔——**抓完務必檢查檔案大小**。

## 產生 PDF

```bash
python3 {skill}/scripts/build_mingge_book.py \
  --md "報告.md" --out "報告.pdf" --fonts ~/fonts-web [--screenshot chk.png]
```

腳本自動判斷三柱/四柱(依 @pillars 行數)。PDF 以無頭 Chromium 列印(環境預裝於 `/opt/pw-browsers/chromium`,勿執行 `playwright install`)。
